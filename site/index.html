Tell the agent what you want. AIDE gives it the tools to wire up your workspace.

Everything an agent needs, in one window

Not a chat sidebar bolted onto an editor — the agent CLIs are first-class citizens.

⌨️

Agent CLIs in tabs

Real terminal sessions that resume on startup, keep their titles, and bind deterministically to their CLI sessions.

🎼

Pipelines & orchestration

Deterministic multi-agent flows: agents, checks, gates, loops and commits. An orchestrator agent drives them over MCP.

🧰

Toolbar as code

Project and personal buttons in toolbar.json — the agent writes them, you click them, output lands in log channels.

📝

Monaco & diff view

A real editor with auto-save, conflict detection and a HEAD-vs-disk diff to review what the agent changed.

🌿

Git-aware file tree

Live status markers, a "modified only" filter, commit dialog with streamed progress.

👥

Accounts & limits

Several accounts per CLI with hot switching and usage display. Proxy settings applied to every agent.

🧠

Thinking & history

See the agent's extended reasoning live, and browse any past session as rendered Markdown.

📱

Remote access

Continue a terminal session from your phone or tablet — scan a QR code and keep going.
