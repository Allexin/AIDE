## Description
Clicking a PNG in the file tree does nothing today (binary files are not opened). Clicking an image, and a context-menu item "Open in viewer" for Markdown, SVG and HTML, should open the file in the viewer window — the same window agents use, without marks mode and with no reply tab unless an agent showed it.
